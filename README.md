# DjangoCommerce 🛒
AI-Integrated Full-Stack E-commerce Platform

A comprehensive shopping platform engineered with Django, featuring real-time payment integration, automated customer communication, and intelligent shopping assistance.

## 🚀 Key Features
- **Guest & Authenticated Checkout:** Seamless shopping experience using the Django Session Framework.
- **Secure Payments:** Integrated with **Razorpay API** for real-time, secure transactions.
- **AI Chat Assistant:** Integrated **LLM (Large Language Model)** providing real-time customer support
- **Stock Management:** Automated inventory tracking system with real-time stock level updates.
- **Automated Invoicing:** Dynamic PDF invoice generation with UTF-8 support.
- **Communication:** Automated order alerts and status updates via **Twilio (WhatsApp/SMS)**.
- **Scalable Architecture:** Optimized database queries and adherence to the clean MVC (Model-View-Controller) pattern.

## 🛠️ Tech Stack
- **Backend:** Django (Python)
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **APIs:** Razorpay, Twilio, Gemini (LLM)
- **Tools:** Git, xhtml2pdf, python-dotenv
